# My Budget Tracker

Track your income and expenses in one place.

## Add Expense

The Add Expense section allows users to enter:

* Expense Name
* Amount
* Category

## Your Expenses

The project includes an expense table with the following categories:

* Food
* Transport
* Rent
* Entertainment
* Other

## Features

* Clean and simple Budget Tracker layout
* Add Expense form
* Styled expense table
* Google Fonts typography
* Responsive design
* CSS cards with padding, borders, spacing, and rounded corners

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## Project Files

* `index.html` — Contains the structure and expense information.
* `style.css` — Contains the visual design and styling.
* `README.md` — Contains information about the project.
